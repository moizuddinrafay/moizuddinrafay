# Security Policy

This portfolio contains educational and professional cybersecurity material.

## Reporting a Sensitive Issue

Do not open a public issue containing credentials, private information or confidential infrastructure details.

If a sensitive issue is discovered, remove the secret from the repository history where appropriate, rotate the affected credential, and handle the matter through an appropriate private channel.

## Scope

The repositories are intended for authorized defensive security research, SOC engineering, detection development and laboratory use.
