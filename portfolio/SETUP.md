# Portfolio website

A responsive static cybersecurity portfolio for Moiz Uddin Rafay. No framework, package installation or build step is needed.

## Preview locally

Run `python3 -m http.server 8000 --directory portfolio` from the repository root, then open http://localhost:8000.

## Publish with GitHub Pages

Open the repository's **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/ (root)**, then save. GitHub will show the actual published URL once deployment completes.

The site is available at the published base URL plus `/portfolio/`. For this repository, the expected URL is https://moizuddinrafay.github.io/moizuddinrafay/portfolio/ after Pages is enabled and deployed.

## Update content

- Edit `portfolio/index.html` to update your biography, experience, credentials, project summaries and professional links.
- Edit `portfolio/style.css` for layout and colors.
- `portfolio/script.js` updates the footer year. The rest of the website works without JavaScript.
