# Cybersecurity Scripts

Small defensive-security utilities and automation examples for SOC, threat intelligence, log analysis and security operations.

## Planned Utilities

- IOC normalization
- Hash extraction
- Log parsing
- IOC list deduplication
- Threat-intelligence response normalization
- Wazuh rule testing helpers
- Report generation
- File integrity checks

## Design Principles

- Defensive and authorized use
- Clear input/output documentation
- Safe defaults
- No embedded secrets
- Error handling
- Test cases
- README documentation

Each tool should include:

```text
README.md
src/
tests/
examples/
requirements.txt
```
