Independent workshops

Training that builds
operating confidence.

Practical learning paths for the people who deploy, investigate and maintain your Wazuh environment.

Administrators

Deployment & administration

Prerequisites
Linux administration and basic networking.

Practical exercise
Build a lab, collect a known event and trace it to the dashboard.

Learning outcomes

  • Explain central components and data flow
  • Deploy a lab and enroll agents
  • Configure collection and agent groups
  • Diagnose connectivity and collection failures

Security engineers

Rules, decoders & integrations

Prerequisites
Working Wazuh knowledge and familiarity with log formats.

Practical exercise
Parse a sample source, implement a detection and demonstrate matching and non-matching tests.

Learning outcomes

  • Extract fields from sample logs
  • Create and test custom rules
  • Tune severity and exceptions
  • Validate integration and notification paths

SOC analysts

Investigation & alert triage

Prerequisites
Basic security concepts and familiarity with endpoint events.

Practical exercise
Investigate a simulated event and write an evidence-based triage note.

Learning outcomes

  • Interpret authentication and file-change events
  • Use searches and dashboards for context
  • Document findings and escalation
  • Understand visibility and detection limitations

Deployment owners

Air-gapped operations & handover

Prerequisites
Familiarity with the client environment; deployment-specific prerequisites agreed.

Practical exercise
Walk through a deployment-specific operating scenario and recovery checklist.

Learning outcomes

  • Understand the deployed architecture
  • Follow approved maintenance procedures
  • Review integration and agent health
  • Use the provided operating runbooks
